# Vibro 17 🤖

![Build APK](https://github.com/Miolonixc/Vibro17/actions/workflows/build.yml/badge.svg)

**Vibro 17** — Android-приложение в стиле Android 17 (Dragon Ball): тёмная тема,
электрический циан и набор вибро-эффектов для любых ситуаций.

> Нажми на карточку эффекта — вибромотор начнёт отыгрывать паттерн.
> Повторное нажатие или кнопка «Стоп» останавливают вибрацию.

## Анимация

Пока играет эффект:

- активная карточка пульсирует (масштаб + свечение рамки);
- в шапке мигает «живой» индикатор (`liveDot`).

Анимации реализованы через `res/anim/pulse.xml` и `res/anim/blink.xml`.

## Можно ли сдвинуть телефон вибрацией? 📱

**Да, частично.** Вибромотор большинства телефонов — это эксцентрик
(ERM, несбалансированный ротор): он создаёт неуравновешенную силу, и из-за
того, что мотор смещён относительно центра масс, телефон при работе
«приплясывает» и может медленно сползать по поверхности.

Чтобы это сработало заметнее:

1. Положи телефон **экраном вверх** на **гладкую, слегка скользкую**
   поверхность (стекло, полированный стол, пластик). На ковре/резиновом
   коврике не поедет.
2. Убери чехол — он гасит смещение.
3. Запусти эффект **«Ползти»** (непрерывная сильная вибрация) — он
   специально подобран, чтобы максимизировать «ползучесть».

Важно: это **неуправляемое** движение. Телефон не поедет в заданную
сторону — он будет описывать дуги/петли, зависящие от положения моторчика
и центра тяжести. Телефоны с линейным вибромотором (LRA, как в iPhone /
флагманах) ползут хуже, чем с классическим эксцентриком.

## Технические детали

- **Язык:** Kotlin
- **Минимальный SDK:** 21 (Android 5.0)
- **Целевой SDK:** 34
- **Амплитуда:** используется на API 26+ (`VibrationEffect.createWaveform`
  с массивом амплитуд). На старых устройствах вибрация работает без
  регулировки силы (грациозная деградация).
- **Разрешение:** `android.permission.VIBRATE` (не требует runtime-запроса).

### Архитектура

```
model/VibroEffect.kt   – data class эффекта (timings / amplitudes / repeat)
model/Effects.kt       – готовый набор пресетов
model/CustomStore.kt   – сохранение пользовательских эффектов в JSON
engine/VibrationEngine.kt – обёртка над Vibrator / VibratorManager
ui/MainActivity.kt     – экран с сеткой эффектов + запуск редактора
ui/EffectAdapter.kt    – RecyclerView-адаптер карточек
ui/CustomActivity.kt   – редактор собственных паттернов (ползунки)
```

## Редактор своих эффектов

Кнопка-карандаш (FAB слева внизу) открывает экран **Редактор**:

- введи название;
- добавляй **шаги** — каждый шаг задаётся двумя ползунками:
  - **Длительность** (10–600 мс) — сколько длится этот сегмент;
  - **Сила** (0–255) — амплитуда; `0` = пауза (вибрации нет);
- **▶ Предпросмотр** проигрывает паттерн сразу;
- **💾 Сохранить** добавляет эффект в сетку на главном экране.

Сохранённые эффекты пишутся во внутренний файл
`custom_effects.json` (`CustomStore.kt`, через `org.json`) и переживают
перезапуск приложения.

Пример паттерна «два удара в дверь» в редакторе:

| Шаг | Длительность | Сила |
|-----|--------------|------|
| 1   | 70 мс        | 255  |
| 2   | 45 мс        | 0    |
| 3   | 70 мс        | 255  |
| 4   | 260 мс       | 0    |

## Сборка

Открой проект в **Android Studio** (или собери через Gradle):

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Установка

Перенеси `app-debug.apk` на устройство и установи (разреши установку из
неизвестных источников).
